# Summary
Weather application to provide temperature history for a specified location and date range.

### Features
This is program utilises the following:
- Functional programming
- Python
- Python packages
- AI model
- User input
- Validation and error handling
- LLM calls
- API call
- JSON
- Data sets
- Data frames
- Data analysis
- Data manipulation
- Graphs
- Saving data via pandas, visualisation via matplotlib

### Functions
1a. Get user input for location  
1b. Validate user input for location (openai) (OpenAI API : 1st Call)  
2.  Get location coordinates for location (openai) (OpenAI API : 2nd Call)  
3.  Get and validate user input for days (try/except)  
4.  Get date range  
5.  Get weather data for location coordinates and date range (requests) (Open-Meteo Weather API)  
6.  Process weather data (pandas)  
7.  Calculate average temperature (per day) (pandas)  
8.  Create graph (matplotlib)  
9.  Save data (pandas) and visualisation (matplotlib)  
10. Calculate and output statistics (min, max, average over date range) (pandas)
